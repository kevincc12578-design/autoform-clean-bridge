更新日期：2026-10-28。对应运行代码基线：`8ff0150`。本树描述新库现状与后续路线；旧库的实现和通过记录不计入新库能力。

## 已验证生命周期

```mermaid
flowchart LR
    A[记录已有工程基线] --> B[创建自有空工程]
    B --> C[读取计数并保存]
    C --> D[关闭并确认页签消失]
    D --> E[重开同一文件]
    E --> F[核对实体计数]
    F --> G[再次保存并关闭]
    G --> H[自有归零 / 基线保留 / worker退出]
```

这里的“读回”仅验证空工程显示的实体计数，不包含材料、工序或求解结果。`lifecycle_ok=true` 与 `e2e_ok=false` 可以同时成立；求解能力尚未实现。
