# 抱箍工序说明

更新日期：2026-10-29。

本路线由项目维护者提供并通过2026-10-28的抱箍操作演示确定，Bridge将这些操作实现为可执行、可核对的自动化流程。原始演示索引为`session-20261028-114837-d70207e2`；原始录像和完整截图保留本地，仓库中的来源记录与验收摘要用于追溯。

## 案例与输入

| 项目 | 本次已验收范围 |
| --- | --- |
| 软件 | 本机AutoForm R13.0.1，中文界面 |
| 零件 | 指定八角管抱箍的`抱箍.STEP` |
| 材料 | `S355MC_4936_4.00.mtb` |
| 板厚 | 4 mm |
| 规划工序 | 从生产线库拖入演示中的U图标工序，规划内显示为C-20 |
| 区域分配 | 将“拉延区域1”分配给C-20 |
| 回弹设置 | 单一测量方案中的自由回弹 |

U图标与C-20是同一规划工序的界面表示，不应解释成两道独立制造工序。本文描述该案例的仿真设置及执行路线；输入路径可配置，不代表已验证任意零件、材料或生产方案。

## 按实际执行顺序说明

开始前，Bridge附着唯一R13会话，记录用户已有工程，创建本轮自有工程并检查其为空。随后按以下顺序执行15个业务步骤：

| 顺序 | 操作 | 设置与核对内容 | Bridge接口 |
| --- | --- | --- | --- |
| 1 | 导入零件 | 导入指定STEP，核对零件出现及输入路径。 | `import_part` |
| 2 | 提取零件 | 执行“提取”，核对动作完成及零件仍存在。 | `extract_part` |
| 3 | 设置冲压方向 | 先“自动设置冲压方向”，再进入角度页，选择方向下拉中的“反向”，读取三轴角度。 | `set_direction` |
| 4 | 设置材料与板厚 | 加载S355MC材料，确认4 mm板厚和材料名称。 | `set_material` |
| 5 | 成型检查 | 选择“弯曲零件”，点击“应用”并等待本次检查完成。 | `forming_check` |
| 6 | 创建规划 | 从空规划开始，将演示中的U图标工序拖入规划，核对C-20出现。 | `create_plan` |
| 7 | 分配区域 | 在C-20列与“拉延区域1”行的交叉单元格完成分配，核对目标格图标。 | `assign_operation` |
| 8 | 访问模面编辑器 | 进入并离开编辑器；本路线忽略压料面，不额外生成压料面或补充面。 | `visit_die_face` |
| 9 | 准备料片 | 选择平板料片，从成型检查复制料片轮廓并提交。 | `copy_blank` |
| 10 | 选择摩擦模型 | 切换到压机线的润滑页，选择库仑摩擦并读取参数。 | `set_friction` |
| 11 | 显示并核对工具 | 显示凸模和凹模，检查已有的自动模型模式及自动接触状态；此步骤不创建模面，也不强制重设模型模式。 | `configure_tools` |
| 12 | 添加参考模型 | 在C-20工序中依次执行“参考→添加→定义→全部输入→确定”；不点击“反转”。 | `add_reference` |
| 13 | 设置回弹 | 创建或确认唯一具名测量方案，在约束条件中设置自由回弹并读回状态。 | `set_springback` |
| 14 | 启动模拟 | 从模拟开始页提交，保存到本轮全新路径，将当前工程、作业及日志关联。 | `start_simulation` |
| 15 | 原生检查与求解 | 对本轮已保存文件的独立副本执行输入检查及完整求解，核对本次Springback成功与所有可解析END返回码为0。 | `solve` |

GUI原工程与原生检查、求解副本分别留证；副本计算不表示结果已回写GUI原工程。录像中的同名保存冲突不属于正常工序，自动化使用新路径。

## 关键参数与动作边界

- **冲压方向反向，参考模型不反转。** 两者是不同页面的不同操作。指定案例三轮读回的冲压角度为X = −180°、Y′ = 0°、Z″ = 0°；这是该输入的观测值，其他模型需重新观察。
- **本路线忽略压料面。** 访问模面编辑器只证明进入和离开；不宣称已生成压料面、补充面或完成全部模面设计。
- **摩擦系数0.15是本次样例的读回值。** 三轮摘要均记录库仑摩擦、`Mill Oil`和摩擦系数0.15；当前接口选择摩擦模型并读取参数，没有主动写入该系数。它不是所有材料与工况的推荐值，空白字段也不代表0。
- **显示、设置与几何有效性分别核对。** 工具可见不代表自动接触已启用；料片轮廓提交不证明已读出闭合拓扑。参考模型按演示不执行反转，但几何方向数值尚未直接读出。

## 保存关闭与验收

业务完成后执行8个保存重开复核步骤：读取业务值→保存原工程→关闭原页签→重开同一文件→再次读取业务值→比较前后业务值→再次保存→关闭重开页签。随后检查自有页签归零并退出Bridge worker，保留用户原有工程。

“每轮26阶段”由**3个会话/空工程步骤、15个业务步骤、8个保存重开复核步骤**组成，是自动化执行计数，不是实体零件的制造工序数量。

2026-10-29保存的验收摘要记录：同一版本从三个独立空工程连续执行，每轮26阶段通过，用时280.155 / 282.801 / 284.173秒，CLI退出码0，三轮命令执行期间零人工点击，同文件业务值一致，两次关闭完成且自有页签归零。这里引用已有验收，不表示本次文档更新重新运行了AutoForm。

当前尚未读取完整AFD全场应力、应变和回弹数值，也未完成产品回弹公差判定或自动回弹补偿。求解成功不能替代产品合格判断。
